Local web app to split one image into multiple horizontally  

https://iryis.github.io/picsplit/

Made with Svelte + Vite + Canvas

## How it works

1. drop in an image
2. Choose amount of tiles (as of right now on twitter they will be in a horizontal layout regardless of what the composer shows)
3. Adjust the trim if needed (most likely not- default 3px)
4. Download each image and upload to twitter in the shown order
5. Attach to your post in order (split1, split2, and so on)
