Local web app to split one image into multiple horizontally  

https://palenightwanderer.github.io/picsplit/

Made with Svelte + Vite + Canvas

## How it works

1. drop in an image
2. Choose amount of tiles, up to 20 (X/Twitter carousels now support up to 20 images)
3. Adjust the trim if needed (most likely not- default 3px)
4. Optionally add overlay text — set its font, weight, size, color, alignment, and shadow, and drag it around the preview to position it
5. Optionally enable "Fit slices to text" so slice cuts are nudged to never cut through the text
6. Choose an export format (PNG, JPG, or WEBP) and quality
7. Download each image, or grab them all as one numbered ZIP, and upload to twitter in the shown order
8. Attach to your post in order (split1, split2, and so on)
